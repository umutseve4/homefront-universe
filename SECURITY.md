# Security Policy

## Supported versions

Security fixes target the current `main` branch. This repository is an experimental browser simulation, not a hosted service or production system.

## Reporting a vulnerability

Please do not include exploit details, credentials, tokens, or private data in a public issue.

If GitHub shows a **Report a vulnerability** option under the repository's Security tab, use it for private reporting. If private reporting is unavailable, open a minimal public issue stating only that you have a security concern and ask the maintainer for a private channel. Do not publish reproduction details until a private channel is established.

Include the affected revision, impacted component, expected impact, and the smallest safe reproduction you can provide.

## Scope

Reports about path handling, generated HTML safety, unsafe browser APIs, dependency or workflow compromise, and unintended data exposure are in scope. Gameplay balance and ordinary feature requests are not security issues.
